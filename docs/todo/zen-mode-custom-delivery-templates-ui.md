# Пользовательские шаблоны сводки доставки для Zen Mode

## Описание
Необходимо реализовать интерфейс (UI) в бекенд-настройках плагина для возможности задавать уникальные шаблоны сводки (`summary_template`) для каждого отдельного инстанса доставки (например, СДЭК, Почта России и т.д.).

## Контекст (Что уже сделано)
Вся логика "под капотом" уже реализована:
1. В `lib/config/storefront.settings.php` определен массив `custom_templates` в секции `delivery`.
2. В `shopPrefillPluginZenMode::getSummaryTemplate` реализовано чтение и подстановка кастомного шаблона по ID инстанса доставки.

Формат хранения данных, который ожидает фронтенд часть плагина:
```php
[zen][groups][delivery][custom_templates][INSTANCE_ID] = [
    'active' => 1, // 1 (true) или 0 (false)
    'template' => 'строка с {$переменными}',
]
```

## Требования к UI настройкам
1. В шаблоне настроек Zen Mode (вероятно, `templates/actions/settings/blocks/tabs/...`) вывести дефолтное поле для общего шаблона доставки.
2. Получить список всех доступных инстансов доставки в магазине (уже реализовано в `shopPrefillPluginSettingsStorefrontAction`).
3. Для каждого инстанса вывести:
   - Чекбокс "Использовать свой шаблон" (привязывается к ключу `active`).
   - Кнопку разворачивания/сокрытия текстового поля.
   - Текстовое поле (textarea) для ввода шаблона (привязывается к ключу `template`).
4. При снятии галочки `active` кастомный шаблон применяться не будет, даже если текстовое поле заполнено. Применяться будет дефолтный `summary_template`.
