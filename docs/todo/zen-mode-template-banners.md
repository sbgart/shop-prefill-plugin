# CSS-классы для баннеров в кастомных шаблонах (Zen Mode)

## Описание
Для того чтобы пользователи могли легко создавать красивые, выделяющиеся кастомные шаблоны для определенных способов доставки и оплаты, необходимо предоставить им набор готовых CSS-классов (баннеров).

Пользователь сможет оборачивать содержимое своего кастомного шаблона в `div` с соответствующим классом, чтобы получить, например, предупреждающий баннер или баннер с информацией об акции.

## Возможные классы (примеры)
- `.prefill-zen-banner-info` — информационный (синий/светлый фон)
- `.prefill-zen-banner-success` — успешный (зеленоватый фон, например, для бесплатной доставки)
- `.prefill-zen-banner-warning` — предупреждение (желто-оранжевый фон, например, "Только предоплата")
- `.prefill-zen-banner-accent` — акцентный (использует `accent_color` из настроек темы/плагина)

## Пример применения в шаблоне пользователя
```html
<div class="prefill-zen-banner prefill-zen-banner-warning">
    <strong>Внимание: Оплата курьеру картой!</strong><br />
    К сожалению, курьер не принимает наличные.
</div>
```

## Необходимые доработки
1. **Frontend CSS (`css/frontend/prefill.zen.css` или аналогичный)**
   - Добавить стили для базового класса `.prefill-zen-banner` (отступы, скругления, базовый цвет текста).
   - Добавить цветовые модификаторы (info, success, warning и т.д.).
2. **Документация (Backend UI)**
   - В интерфейсе редактирования кастомных шаблонов (в админке) добавить небольшую подсказку / хелпер с примерами HTML-кода использования этих баннеров, чтобы администратор магазина мог просто скопировать и вставить нужный блок.
