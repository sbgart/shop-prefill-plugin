Как работает плагин

Плагин подготавливает привычный сценарий оформления, не заменяя механизмы Shop-Script: расчёты, доступность и проверка заказа остаются у движка.

Предзаполнение

Плагин подготавливает. Shop-Script рассчитывает

Плагин возвращает сохранённые данные в штатный процесс оформления, а дальше заказ обрабатывает сам движок.

  1. 1
    Покупатель возвращается Плагин

    Если постоянная авторизация включена, плагин продлевает авторизацию на сайте. Входить заново не нужно.

  2. 2
    Открывает корзину Плагин

    Перед штатной обработкой плагин добавляет в сессию оформления данные прошлого заказа — и только в те блоки, которые покупатель ещё не заполнил сам.

  3. 3
    Заказ пересчитывается Shop-Script

    Движок запускает обычную калькуляцию по текущей корзине, адресу и настройкам магазина.

  4. 4
    Остаются доступные варианты Shop-Script

    Shop-Script проверяет сохранённую доставку для текущего адреса и заказа. Недоступный вариант сбрасывается, а покупатель видит актуальный выбор.

Плагин ничего не рассчитывает сам и не меняет правила доставки — он только передаёт сохранённые данные в штатный конвейер Shop-Script.

Дзен-режим

Длинная, отвлекающая форма — в понятную сводку

Дзен-режим включается после штатной обработки формы и никогда не подменяет проверку Shop-Script.

  1. 1
    Форма обрабатывается Shop-Script

    Shop-Script возвращает актуальные данные и ошибки каждого блока оформления заказа.

  2. 2
    Проверяется готовность Плагин

    Плагин проверяет, достаточно ли данных и нет ли ошибок. Пустой или проблемный блок не сворачивается.

  3. 3
    Блок сворачивается Плагин

    Только заполненный блок без ошибок сворачивается в компактную карточку с кнопкой «Изменить».

  4. 4
    Любая ошибка остаётся на виду Shop-Script + плагин

    Shop-Script возвращает ошибку — плагин сразу раскрывает нужный блок. Поле и сообщение видны покупателю.

Дзен-режим меняет только представление формы. Валидация и создание заказа остаются за Shop-Script.

Что ещё умеет плагин

Помнит и гостевые покупки

Данные можно использовать при следующем визите в том же браузере. По умолчанию сохранение требует согласия покупателя.

Не спорит с покупателем

Ручной ввод всегда важнее истории: изменённые или удалённые покупателем данные плагин не возвращает обратно.

Интеграции с другими плагинами

Передаёт город последнего заказа в CitySelect, «SEO-регионы» и «Доставку и платежи» вместо определения по IP, которое может ошибаться, например при использовании VPN.

Гибкая система шаблонов

Настройте сводки для конкретной доставки или оплаты: сроки, адрес и расписание ПВЗ, фотографии, описание и дополнительные поля. Результат сразу виден в предпросмотре.

Вы сами задаёте границы

Отдельно включайте заполнение данных покупателя, доставки, оплаты и подтверждения заказа.

Настройки для каждой витрины

Функции, тексты, шаблоны, иконки, цвета и CSS можно настраивать отдельно для разных витрин магазина.
