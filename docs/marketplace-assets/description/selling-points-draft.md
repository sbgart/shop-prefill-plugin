# Страница продажи плагина — список преимуществ

**Создан:** 26.08.2026
**Статус:** черновик, тезисы. Готовый текст карточки в магазине Webasyst — [store-description-ru.md](store-description-ru.md)

Задача файла — собрать в одном месте всё, за что покупатель платит, короткими тезисами. Формулировки правим здесь, в описание для магазина переносим готовыми.

---

## Главное обещание

**Постоянный покупатель оформляет заказ в один клик, а не заполняет форму заново каждый раз.**

Плагин помнит, куда и как человек заказывал в прошлый раз, и подставляет это в корзину: контактные данные, адрес, способ доставки, способ оплаты.

---

## Преимущества

### Предзаполнение из истории заказов

- Форма заказа открывается уже заполненной: имя, телефон, email, адрес, доставка, оплата.
- Работает и для **гостей без регистрации** — по защищённому токену в браузере, если покупатель дал согласие.
- Каждый следующий заказ короче предыдущего.

### Автоопределение города, которое не ошибается

- Обычные плагины выбора города определяют его по IP-адресу. При VPN, мобильном интернете или корпоративной сети это регулярно даёт чужой город — покупатель видит «Москва», хотя живёт в Новосибирске.
- Плагин передаёт городским плагинам (**CitySelect**, **SEO-регионы**) город из **последнего заказа покупателя**. Данные о реальной покупке точнее любой геобазы.
- Всплывающее окно «Ваш город — Москва?» больше не показывается: спрашивать нечего, город уже известен.
- Город в шапке сайта и город в корзине совпадают — исчезает классическая путаница «на сайте один город, в доставке другой».
- Экономия на внешнем сервисе: запрос к геобазе (DaData) не выполняется вовсе.
- Приоритет всегда у покупателя: сменил город вручную — плагин больше его не трогает.
- Переходы между витринами не инициируются: настройки магазина остаются в силе.

### «Мои варианты доставки»

- Покупатель выбирает из своих прошлых сценариев доставки одним кликом: «Курьер на Ленина, 5», «ПВЗ у метро», «Почта на дачу».
- Показываются только реально доступные сейчас способы: отключённые администратором не предлагаются.
- Количество вариантов настраивается.

### Дзен-режим оформления

- Заполненные блоки корзины сворачиваются в компактные карточки — покупатель видит короткую сводку вместо шести длинных секций.
- Шаблон сводки настраивается: логотип службы доставки, срок, цена, адрес.
- Разворачивается одним кликом, если что-то нужно изменить.

### Аккуратность к данным покупателя

- Введённое покупателем никогда не перезаписывается — даже если он стёр поле намеренно.
- Гостевые данные хранятся по производному идентификатору: утечка параметров заказа не даёт восстановить чужую сессию.
- Есть кнопки «очистить мои данные» и «отозвать согласие» — по 152-ФЗ.
- Просмотр каталога не создаёт ни куки, ни записи в базе: анонимный посетитель для плагина не существует.

### Настройка под магазин

- Индивидуальные настройки на каждую витрину плюс общие для всех.
- Включается и выключается посекционно: контакты, доставка, оплата, комментарий.
- Тёмная тема поддержана.
- Локализация: русский и английский.

## Ещё тезисы (сырые, отобрать позже)

- Меньше брошенных корзин: чем меньше полей, тем выше конверсия у возвращающихся.
- Мобильный трафик выигрывает сильнее всего — там заполнение формы дороже всего для покупателя.
- Ничего не требует от покупателя: не нужно регистрироваться, чтобы получить предзаполнение.
- Совместим с популярными плагинами города и доставки, не конфликтует за поля формы.
- Не переопределяет вёрстку темы: работает с любой темой на checkout 2.0.
- Не замедляет каталог: на страницах без корзины плагин почти ничего не делает.

## Что писать честно

- Интеграции с городскими плагинами включаются вручную и выключены по умолчанию.
- Подавление окна выбора города зависит от шаблонов темы: если тема переписана, поведение может отличаться.
- Гостевое предзаполнение требует согласия покупателя, если магазин его требует.
