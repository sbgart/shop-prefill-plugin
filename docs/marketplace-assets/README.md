# Материалы карточки в магазине Webasyst

Здесь лежит всё, что нужно для подготовки и публикации карточки плагина. Папка не входит в архив плагина: `docs/` исключается из `prefill.tar.gz`.

## Что загружать и вставлять

- `banner/prefill-marketplace-banner-400x220.png` — иконка карточки, готова к загрузке: ровно 400×220 px.
- `description/ru.md` — основной русский текст для карточки.
- `description/previews/` — три самостоятельных HTML-варианта оформления описания. Перед вставкой в магазин заменить локальные пути к снимкам URL-адресами загруженных изображений.
- `screenshots/current/` — актуальные скриншоты, которые используются в описании.

## Рабочие материалы

- `banner/drafts/` — предыдущие варианты баннера; не загружать в магазин.
- `screenshots/archive/` — сохранённые старые снимки; не загружать в магазин.
- `description/selling-points-draft.md` — черновик тезисов для редактуры.
- `work-notes/screenshot-refresh-plan.md` — план пересъёмки витринных скриншотов.
