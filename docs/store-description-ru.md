# Описание плагина для магазина Webasyst (черновик)

> Черновик страницы плагина для store.webasyst.ru. Места для скриншотов отмечены отдельно — после реализации вставить туда изображение с указанным содержимым.

---

## Заголовок

**Prefill — предзаполнение корзины и Дзен-режим оформления заказа**

Коротко: плагин запоминает данные покупателя и сокращает оформление заказа до пары кликов.

## Описание (для карточки/превью, 1-2 предложения)

Plugin автоматически подставляет в корзину данные из прошлых заказов покупателя (контакты, адрес, способ доставки и оплаты) и сворачивает уже заполненные шаги в компактную сводку — оформление заказа для постоянного клиента занимает не больше пары кликов вместо повторного заполнения формы с нуля.

---

## Зачем этот плагин

Каждый лишний шаг в корзине — повод её закрыть. Постоянный покупатель, который уже один раз указал адрес, телефон и способ доставки, не должен вводить это заново при втором, третьем и десятом заказе. Стандартная корзина Shop-Script всегда показывает полную форму — даже тем, кто покупает у вас не первый раз.

**Prefill решает это в два этапа:**

1. **Предзаполняет** поля данными из истории заказов — для авторизованных покупателей и для гостей (по cookie, с согласия).
2. **Сворачивает** заполненные шаги в краткую сводку (Дзен-режим) — покупатель видит не форму с десятком полей, а понятную сводку «куда» и «как» с кнопкой «Изменить», если что-то нужно поправить.

Результат — меньше отказов на этапе оформления и быстрее повторные покупки.

> 📸 **Скриншот 1.** Сравнение «было / стало»: слева — стандартная развёрнутая форма оформления заказа со всеми полями, справа — та же корзина с Дзен-режимом: свёрнутые секции «Покупатель», «Доставка», «Оплата» с краткой сводкой и кнопкой «Изменить».

## Функция 1. Предзаполнение полей

Плагин подставляет данные в форму оформления заказа, опираясь на:

- **профиль покупателя** — если он авторизован;
- **историю его заказов** — последний оформленный заказ как основной источник;
- **cookie гостя** — если покупатель не авторизован, но уже заказывал ранее (с его согласия на сохранение данных).

**Что заполняется:**

- Контакты: имя, телефон, email, данные компании (для юрлиц), ИНН;
- Регион и адрес доставки: страна, город, улица, дом, квартира;
- Способ доставки и его параметры (включая кастомные поля плагинов доставки);
- Способ оплаты (включая кастомные поля плагинов оплаты);
- Комментарий к заказу.

**Дополнительные возможности:**

- **«Мои варианты доставки»** — диалог с адресами и способами доставки из последних заказов покупателя, чтобы не вводить новый адрес, если уже есть подходящий;
- **Гибкая настройка по блокам** — администратор включает или отключает предзаполнение отдельно для блоков «Покупатель», «Доставка», «Оплата», «Подтверждение»;
- **Продление авторизации** — настраиваемый срок, на который продлевается вход постоянного покупателя при каждом визите в магазин;
- **Согласие гостя на сохранение данных** — отдельная галочка «Запомнить мои данные для следующего заказа», обязательна по умолчанию для соответствия требованиям о хранении персональных данных; администратор может отключить запрос согласия;
- **Настройки по каждой витрине** — отдельная конфигурация, если у магазина несколько витрин.

> 📸 **Скриншот 2.** Заполненная форма оформления заказа: видно, что поля «Имя», «Телефон», «Адрес», «Способ доставки» уже подставлены, а рядом с адресом — кнопка/ссылка «Мои варианты доставки», открывающая список адресов из прошлых заказов.

> 📸 **Скриншот 3.** Настройки плагина, вкладка «Общие»: блок переключателей по секциям предзаполнения («Покупатель», «Доставка», «Оплата», «Подтверждение») и настройка согласия гостя.

## Функция 2. Дзен-режим

Когда поля уже заполнены, корзина со всеми открытыми блоками выглядит избыточно. Дзен-режим сворачивает заполненные шаги в одну строку с краткой сводкой — покупатель видит итог, а не форму.

**Как это выглядит:**

- Блок «Покупатель» сворачивается в строку вида `Иван Петров • +7 999 123-45-67`;
- Блок «Доставка» — в строку с названием способа, стоимостью и адресом (с учётом типа доставки — курьер, пункт выдачи или почта показывают разные данные в сводке);
- Блок «Оплата» — в строку с названием способа оплаты;
- Рядом со сводкой — кнопка «Изменить», по которой блок разворачивается обратно в полную форму.

**Что можно настроить:**

- Включать или отключать сворачивание для каждого блока отдельно;
- Шаблон текста сводки для каждого блока — через переменные (`{firstname}`, `{phone}`, `{city}`, `{shipping_name}` и др.), с поддержкой условий;
- Свой шаблон сводки для конкретного способа доставки или оплаты, если у магазина их несколько и они существенно отличаются;
- Источник иконки рядом со сводкой — логотип способа доставки/оплаты, стандартная иконка блока, аватар покупателя или без иконки вообще;
- Размер иконок и дополнительные CSS-классы для кнопок — чтобы вписать в дизайн темы.

**Защита от ошибок:** блок не сворачивается, если в нём остались незаполненные обязательные поля или ошибка валидации — покупатель сначала видит и исправляет проблему, и только потом блок сворачивается в сводку.

> 📸 **Скриншот 4.** Развёрнутый блок «Доставка» с кнопкой «Свернуть» внизу — для иллюстрации, что переключение между режимами доступно в любой момент.

> 📸 **Скриншот 5.** Настройки плагина, вкладка «Дзен-режим»: переключатели по блокам, выбор источника иконки и поле редактирования шаблона сводки с примером синтаксиса.

## Настройка под дизайн магазина

- Акцентный цвет элементов плагина — чтобы кнопки и сводки вписывались в цветовую схему темы;
- Поле для собственного CSS — для тонкой подгонки внешнего вида под нестандартные темы;
- Дополнительные CSS-классы для кнопок «Мои варианты», «Изменить», «Свернуть».

> 📸 **Скриншот 6.** Настройки плагина, вкладка «Дизайн»: поле выбора акцентного цвета и текстовое поле для кастомного CSS.

---

## Почему это увеличивает продажи

- **Меньше отказов в корзине** — постоянный покупатель не уходит, не дойдя до конца формы, потому что форма короче;
- **Быстрее повторные покупки** — оформление в один-два клика мотивирует возвращаться за повторным заказом;
- **Меньше ошибок ввода** — данные подставляются из уже подтверждённого заказа, а не вводятся заново;
- **Магазин выглядит современнее** — сравнение с маркетплейсами (Wildberries, Ozon, Яндекс Маркет), где оформление заказа для постоянного покупателя занимает секунды.

## Совместимость

- Shop-Script 10.0 и новее;
- PHP 7.4 и новее;
- Совместим со сторонними плагинами доставки и оплаты — сводка Дзен-режима не перекрывает их кастомные поля и хуки.

## Что появится в следующих версиях

- **Заказ в один клик** — кнопка «Купить» на странице товара сразу переводит в оформление заказа с уже заполненными данными, минуя добавление в корзину вручную;
- Выбор пункта выдачи прямо со страницы товара или из любого места сайта, без перехода в корзину;
- Опция «Оплата после получения» как отдельный способ оплаты;

- Бейдж на свёрнутом блоке с подсказкой, какие дополнительные данные можно заполнить в секции (например, ИНН в оплате или email в данных покупателя);
- Интеграция с плагином «Фильтр доставки и оплаты» для диалога «Мои варианты доставки».
