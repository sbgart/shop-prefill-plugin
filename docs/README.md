# Документация плагина «Автовыбор доставки и оплаты» (prefill)

Плагин предзаполняет форму оформления заказа Shop-Script данными из прошлых заказов покупателя и сворачивает заполненные блоки в компактные карточки (Дзен-режим).

**Архитектура кода** (хуки, классы, поток данных, известные грабли) — не здесь, а в [../AGENTS.md](../AGENTS.md) в корне плагина (`CLAUDE.md` — симлинк на него). Здесь — документация для пользователей плагина и рабочие материалы по разработке: концепция, баги, тесты, релизы.

## Рабочие процессы

Повторяющиеся операции описаны в `.ai/commands/` в корне Webasyst и доступны как slash-команды Claude Code:

- Локализация — `/compile-plugin-mo` (компиляция `.po` и сброс всех уровней кэша переводов).
- Релиз — `/release-start`, `/release-pack`, `/release-publish`; сборка минифицированных бандлов — `/build-plugin-frontend` (вызывается из `/release-pack`).
- Ревью и тесты — `/plugin-review`, `/plugin-test`.

Ключи локализации — точечная нотация: `error.*`, `setting.*`, `hint.*`, `tab.*`, `zen.*`, `dialog.*`. Любой новый текст интерфейса сразу в обе локали (`ru_RU`, `en_US`).

## Правила ведения задач

- Сырая идея без разбора — одна строка в разделе Backlog файла [TODO.md](TODO.md). Появился разбор — файл в `todo/`, строка становится ссылкой.
- Баг или находка ревью, требующие разбора, — файл в `bugs/` или `codereview/`, строка в TODO.md обязательна.
- Задача закрыта — строка уходит в [archive/DONE.md](archive/DONE.md), файл переносится в `done/` подпапку того же каталога (`git mv`) с поправкой относительных ссылок.
- Баг, найденный во время прогона тестов, заводится в `bugs/` и линкуется из отчёта прогона, а не описывается внутри отчёта.
