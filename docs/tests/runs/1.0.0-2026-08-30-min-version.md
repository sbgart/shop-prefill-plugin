# Прогон 1.0.0 — 2026-08-30 (минимальная версия, Docker)

**Режим:** точечный (SMOKE + мультивитрины + гость) — не заменяет режим R на основном стенде, закрывает S-01/S-08 из TEST-PLAN.md §8.
**Сборка:** рабочее дерево feature/geo-sync-stage1, после фикса апострофа (docs/bugs/smarty-quote-break-old-webasyst.md).
**Стенд:** `webasyst-framework v2.9.0` (installer 2.9.0), `shop-script v10.0.0`, PHP 7.4.33, MariaDB 10.5, Apache. Docker-compose `~/Project/shop10-docker`. Три точки входа: `shop10.wa-dev.loc/*` (основная), `shop10.wa-dev.loc/shop-1/*` (K5, путь), `shop-1.shop10.wa-dev.loc/*` (K6, поддомен) — все три указывают на приложение `shop`, вторые две — на одну и ту же вторую витрину. UI бэкенда — Webasyst 2.0 (плагин требует именно её, классический UI 1.3 не поддерживается — см. docs/bugs/settings-waswitch-missing-legacy-ui.md).
