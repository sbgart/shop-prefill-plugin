# Issue 52 — Публичные фронтовые эндпоинты: флуд лога и отсутствие CSRF

**Статус:** ⬜ Открыта
**Приоритет:** 🟠 Высокий
**Сложность фикса:** 🔧 Небольшой
**Файлы:** `lib/actions/frontend/shopPrefillPluginFrontendConsent.controller.php`, `...FillCheckoutParams`, `...ApplyDelivery`, `lib/classes/log/shopPrefillPluginLog.class.php`

## Проблема 1 — неограниченный рост лог-файла из анонимного запроса

```php
default:
    shopPrefillPluginLog::warning('Unknown action received in consent controller', ['action' => $action]);
```

- эндпоинт `prefill/consent` доступен **без авторизации**;
- `action` приходит из POST и попадает в лог целиком;
- уровень `warning` пишется при **дефолтной** настройке логирования (`logging.level = warning`).

Любой посетитель может в цикле слать запросы и раздувать `wa-log/prefill.plugin.error.log` — ротации у плагина нет, файл растёт до заполнения диска. Плюс это классическая log injection: содержимое строки контролируется извне (в админке экранируется, но сам файл засоряется).

То же касается любых других `warning/error`-веток, куда попадают сырые пользовательские данные.

## Проблема 2 — нет CSRF-защиты

`prefill/consent` (`grant` / `revoke` / `clear` / `clear_form`), `prefill/fill-checkout-params`, `prefill/apply-delivery` принимают POST без токена. Сторонний сайт может:

- проставить «согласие на сохранение данных» без действия пользователя (юридически значимая галочка — 152-ФЗ/GDPR);
- очистить историю предзаполнения и данные формы посетителя.

SameSite=Lax по умолчанию в браузерах снимает большую часть риска, но опираться только на это для галочки согласия не стоит.

## Рекомендация

1. Не логировать сырое значение `action`: сравнивать со списком допустимых, в лог писать `'invalid'` или обрезанное/санитизированное значение; понизить уровень до `debug`.
2. Ввести простой rate-limit или писать «неизвестное действие» не чаще N раз за сессию.
3. Добавить ротацию/ограничение размера лог-файлов плагина (или писать через `waLog` с его правилами).
4. Для `grant`/`revoke` использовать CSRF-токен (`wa()->getStorage()`/`waRequest::post('_csrf')`), проверять `Sec-Fetch-Site`/origin.
