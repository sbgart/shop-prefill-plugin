# Issue 03 — Неправильный источник данных для подтверждения заказа

**Статус:** ✅ Исправлено  
**Приоритет:** 🔴 Высокий  
**Сложность фикса:** ⚡ Минутный  
**Файл:** `fillparams/shopPrefillPluginFillParamsProvider.class.php`, строки 322–326

## Проблема

Переменная `$confirm_params` бралась из секции `payment` массива чекаута, тогда как комментарий находится в `confirm`. Поле `comment` из `payment` никогда не существует, из-за чего комментарий из текущего процесса чекаута не считывался для предзаполнения.

```php
// Было
$confirm_params = $checkout_params['order']['payment'] ?? [];
```

## Исправление

Изменён ключ для извлечения параметров подтверждения (заменён `payment` на `confirm`):

```php
// Стало
$confirm_params = $checkout_params['order']['confirm'] ?? [];
```
