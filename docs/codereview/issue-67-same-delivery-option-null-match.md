# Issue 67 — `isSameDeliveryOption()`: `null` у кандидата совпадает с чем угодно, варианты схлопываются

**Статус:** ⬜ Открыта
**Приоритет:** 🟠 Средний (функциональная потеря данных в диалоге «Мои варианты»)
**Сложность фикса:** ⚡ Минутный
**Файл:** `lib/classes/fillparams/shopPrefillPluginFillParams.class.php:477`

## Проблема

```php
} else {
    // Строгое (но без приведения типов) сравнение
    if ($this_value !== null && $this_value != $other_value) {
        return false;
    }
}
```

Если у `$this` поле не заполнено (`null`), проверка **пропускается**, и объекты считаются одинаковыми по этому полю независимо от значения `$other`. [issue-23](done/issue-23-is-same-delivery-one-sided-comparison.md) исправила одностороннее сравнение массивов, но скалярную ветку не тронула — там односторонность осталась.

## Последствия

`isSameDeliveryOption()` — ядро дедупликации в `getFillParamsCollection()`:

```php
foreach ($seen_delivery_options as $seen) {
    if ($candidate->isSameDeliveryOption($seen)) { $is_duplicate = true; break; }
}
```

Обход идёт от новых заказов к старым, `$candidate` — более старый заказ. Достаточно, чтобы у него не было одного поля (например, `street` — самовывоз без адреса, или `zip`, которого не было в старой конфигурации чекаута), и он будет признан дублем свежего варианта с другим адресом. Покупатель не увидит свой прошлый вариант доставки в диалоге, при этом в логе — тишина.

Второй потребитель — подсветка текущей карточки:

```php
$item_array['is_current'] = $item_obj->isSameDeliveryOption($current);
```

`$current` строится из checkout-сессии и заполнен частично (а при [issue-66](issue-66-shipping-variant-id-dot-split.md) — ещё и без shipping_id). Здесь `$this` — элемент коллекции, поэтому направление другое, но эффект тот же: «активными» могут отметиться несколько карточек сразу.

## Рекомендация

1. Сравнивать симметрично, приводя «пусто» к общему виду:

   ```php
   $left  = $this->$property  ?? '';
   $right = $other->$property ?? '';

   if (is_array($left) || is_array($right)) {
       if ($left != $right) { return false; }
   } elseif ((string) $left !== (string) $right) {
       return false;
   }
   ```

   Строковое приведение сохраняет нынешнюю терпимость к `5` vs `'5'` (shipping_id из БД приходит строкой), но убирает «null совпадает со всем».
2. Проверить в браузере: два заказа с одинаковым способом доставки, но разными адресами (и один — самовывоз без улицы) → в диалоге должны остаться обе карточки.
3. Заодно решить судьбу `$this->active` / `isActive()` / `setActive()` в этом же классе — поле нигде не устанавливается, см. [issue-71](issue-71-dead-code-in-release-archive.md).
