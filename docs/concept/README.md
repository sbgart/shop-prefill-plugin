# Концепция плагина Prefill

Документация по разработке и концепции плагина.

## 📄 Файлы

### [RULES.md](RULES.md)
Инварианты плагина — короткий свод правил, которые нельзя нарушать:
- Приоритет ввода покупателя, два признака непустоты секции
- Назначение снапшота, разделение «рендер vs состояние»
- Правила дзен-режима и границы вмешательства в ядро

**Читать первым перед правкой чекаут-логики.** Проверки к правилам — в [../tests/TESTS.md](../tests/TESTS.md).

### [CONCEPT.md](CONCEPT.md)
Основной файл концепции плагина:
- Описание функциональности
- Примеры корзин для изучения
- Логика и идеи для реализации
- Что надо проверить
- Известные баги

### [ZEN-MODE.md](ZEN-MODE.md)
Концепция Дзен-режима корзины:
- Сворачивание секций с предзаполненными данными
- Группы, секции, хуки чекаута
- Логика отображения и cookies

### [ONE-CLICK-BUY.md](ONE-CLICK-BUY.md)
Концепция покупки в один клик:
- Поток: товар → checkout → оформление без заполнения полей
- Исследование API корзины и чекаута Shop-Script

### [VALIDATION.md](VALIDATION.md)
Техническая документация по валидации полей:
- Два типа ошибок в Shop-Script (критические и отложенные)
- Где находятся ошибки в структуре `$params`
- Готовый код для проверки перед скрытием полей
- Примеры структур данных

## 🎯 Назначение

Эта папка содержит рабочую документацию для разработки плагина:
- Идеи и заметки в процессе разработки
- Технические решения и их обоснование
- Проблемы и способы их решения
- Чек-листы для проверки

**Для пользовательской документации см. [../guides/](../guides/)**
