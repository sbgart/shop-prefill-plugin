# Release Notes v1.0.0

**Дата:** 2026-08-08

## Что нового

- Предзаполнение полей чекаута на основе истории заказов покупателя (для авторизованных и гостей).
- Zen Mode — автоматическое сворачивание уже заполненных секций чекаута («Покупатель», «Доставка», «Оплата»).
- Интеграции с CitySelect и DP (delivery point).

## Исправления

- Свёрнутый блок «Покупатель» без имени/телефона теперь показывает понятную подсказку вместо пустого разделителя «•».
- Дефолтные иконки свёрнутых блоков корректно отображаются в тёмной теме витрины.
