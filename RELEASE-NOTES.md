# Release Notes v1.0.2

**Дата:** 2026-10-08

## Что нового

- Панель отладки больше не требует режима отладки Webasyst. Раньше ради неё приходилось переводить в режим отладки весь сайт, поэтому на работающем магазине ею фактически нельзя было пользоваться. Теперь она включается одной настройкой плагина («Отладка → Панель отладки на витрине») и видна только пользователям с полным доступом к магазину — например, временному аккаунту, который магазин создаёт для поддержки. Вместе с панелью включается подробный журнал из браузера. Панель показывается только на странице оформления заказа.

## Исправления

- Безопасность: панель отладки и её запросы больше не доступны обычным посетителям. Раньше при включённых режиме отладки Webasyst и настройке панели её видел любой посетитель на любой странице, а данные сессии оформления заказа отдавались без проверки прав. Теперь все запросы панели требуют полного доступа к магазину и защищены CSRF-токеном.

## Известные ограничения

- Настройка «Запомнить меня» продлевает только уже выданный ядром `auth_token` и работает только при включённом тумблере `rememberme` у домена; кастомный срок жизни токена — best-effort.
