# Release Notes v1.0.0

**Дата:** 2026-09-13

## Что нового

- Предзаполнение полей чекаута на основе истории заказов покупателя (для авторизованных и гостей).
- Zen Mode — автоматическое сворачивание уже заполненных секций чекаута («Покупатель», «Доставка», «Оплата»).
- Интеграции с CitySelect и DP (delivery point).
- Интеграция с плагинами выбора города — «Автоопределение и выбор города» (CitySelect) и «SEO-регионы»: плагин передаёт им город из последнего заказа покупателя раньше, чем они запустят собственное определение по IP, так что окно «Ваш город?» не показывается, а город в шапке сайта совпадает с городом в корзине. Приоритет всегда за покупателем; включается отдельным тумблером на каждую витрину, по умолчанию выключено.

## Исправления

- Свёрнутый блок «Покупатель» без имени/телефона теперь показывает понятную подсказку вместо пустого разделителя «•».
- Дефолтные иконки свёрнутых блоков корректно отображаются в тёмной теме витрины.
- Страница оформления заказа больше не падает с фатальной ошибкой, если поле формы приходит с несколькими значениями вместо одного (мультиселект, группа чекбоксов от соседнего плагина или темы) — все точки входа плагина закрыты страховкой от неизвестных ошибок.
- Настройки витрины больше не теряются при смене её адреса (смена главной страницы, переименование URL раздела или домена) — витрина определяется по постоянному идентификатору, а не по адресу.
- Свёрнутые карточки «Доставка»/«Оплата» и их иконки больше не пропадают при коротком замыкании конвейера ядра или ускоренном первом рендере страницы (`fast_render`).
- Ошибка на шаге авторизации больше не стирает выбранные доставку и оплату — последний подтверждённый выбор восстанавливается, если адрес не менялся.
- Безопасность: данные покупателя в сводке Zen Mode и в диалоге «Мои варианты» теперь выводятся экранированными (защита от XSS через имя/адрес/кастомные поля).
- Колонка `value` таблицы `shop_prefill_settings` расширена до `MEDIUMTEXT` — кастомный CSS витрины больше не рискует не сохраниться при превышении старого лимита в 64 КБ (миграция применяется автоматически).
- Часы работы и фотографии пункта выдачи снова корректно выводятся в свёрнутой карточке Zen Mode, с собственным адаптивным оформлением.
- Устаревшие сгенерированные CSS/JS-файлы в `wa-data` теперь удаляются автоматически, не задевая кастомный CSS витрины.
- Cookie согласия (`prefill_consent`) теперь ставится с `secure` и `SameSite=Lax`.

## Известные ограничения

- Настройка «Запомнить меня» продлевает только уже выданный ядром `auth_token` и работает только при включённом тумблере `rememberme` у домена; кастомный срок жизни токена — best-effort.
